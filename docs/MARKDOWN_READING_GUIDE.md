# Reading the Markdown Documentation

## Recommended viewer

Open the repository folder as an Obsidian vault for the easiest reading and navigation experience. Use VS Code Markdown Preview while editing.

### VS Code

Open a Markdown file and press:

```text
Ctrl + Shift + V
```

Suggested settings:

```json
{
  "window.zoomLevel": 1,
  "markdown.preview.fontSize": 18,
  "markdown.preview.lineHeight": 1.6
}
```
