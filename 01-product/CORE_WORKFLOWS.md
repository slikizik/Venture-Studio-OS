# Core Workflows

1. Create project from template.
2. Define Project Brain.
3. Confirm project stages and quality gates.
4. Create deliverables.
5. Create work packets linked to deliverables.
6. Produce and attach outputs or evidence.
7. Submit work for review.
8. Approve, reject, or request revision.
9. Record decisions and risks.
10. Release a project version.
11. Capture feedback and create improvement work.
