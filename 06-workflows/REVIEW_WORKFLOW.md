# Review Workflow

1. A submitted work packet creates one pending review.
2. The reviewer evaluates every acceptance criterion.
3. Each criterion must be `PASSED`, `FAILED`, or `WAIVED` with a reason.
4. Approval is permitted only when all criteria pass or have an approved waiver.
5. Revision request must identify required changes.
6. Rejection must state why revision is not appropriate.
7. Decisions and comments become immutable after submission.
8. A corrected review supersedes, but never overwrites, the prior record.
