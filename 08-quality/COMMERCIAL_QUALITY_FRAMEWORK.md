# Commercial Quality Framework

VSO separates **functional completion** from **commercial readiness**.

## Universal quality dimensions

Every project Quality Profile selects relevant dimensions and target levels:

- outcome/requirement fit;
- correctness;
- reliability and recoverability;
- user experience/readability/usability;
- accessibility where relevant;
- performance where relevant;
- security/privacy where relevant;
- maintainability/revisionability;
- documentation/instructions;
- installation/distribution/presentation;
- consistency and polish;
- project-type-specific expert quality.

## Target levels

`BASIC`, `COMPETITIVE`, `COMMERCIAL`, `COMMERCIAL_PLUS`, `DIFFERENTIATOR`.

A project may intentionally set different targets per dimension. “World class” without benchmark evidence is not an accepted target.

## Project-type examples

Software adds architecture, testing, compatibility, deployment, error handling, security, performance, maintainability, installation, and supportability.

Books add audience fit, story/content quality, readability, editing, illustration consistency, layout, proofing, presentation, and publishing readiness.

Learning products add learning outcomes, pedagogy, engagement, content accuracy, assessment validity, progression, accessibility, retention evidence, and technical quality.

## Release rule

A project may not be labelled commercially ready solely because all functional tests pass. The Release Readiness Model must evaluate the project Quality Profile and unresolved benchmark gaps.
