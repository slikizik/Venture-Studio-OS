# Non-Functional Requirements

- **NFR-001** — Application must run locally on Windows 11 and Ubuntu LTS.
- **NFR-002** — All persisted data must survive application restart.
- **NFR-003** — TypeScript strict mode must pass without errors.
- **NFR-004** — Core pages must meet WCAG 2.1 AA keyboard and contrast expectations.
- **NFR-005** — Primary list and dashboard actions should respond within two seconds at MVP data volume.
- **NFR-006** — Rendered Markdown and user text must be sanitized.
- **NFR-007** — Production release must have no unresolved critical dependency vulnerabilities.
- **NFR-008** — All dates must be stored in UTC and displayed in owner timezone.
- **NFR-009** — Critical records and decisions must be append-only or versioned.
- **NFR-010** — Every completed requirement must link to passing evidence.
