# Runtime Script Contracts

Hermes must implement these scripts using the approved project technology and host operating-system support during the relevant build phase:

- `create-worktree`
- `allocate-port`
- `create-environment`
- `start-environment`
- `stop-environment`
- `list-environments`
- `remove-environment`
- `check-environment-isolation`
- `compare-with-main`
- `prepare-merge`

Until implementation, these names are contracts, not completed functionality. Phase reports must not claim they work until tests prove them.
